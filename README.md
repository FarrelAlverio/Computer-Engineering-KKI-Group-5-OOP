# Yey's Skii 🎵

**Yey's Skii** is a 2D musical adventure platformer game featuring YE, a character inspired by Kanye West. The game takes place in a snowy pixel-art city filled with music, obstacles, enemies, and exciting challenges.

Players must jump between rooftops, avoid obstacles, collect items, and defeat enemies using different musical weapons to reach the final YEE Concert.

## 🎮 Game Features

- **Platformer Gameplay** - Explore the maps, jump between blocks/buildings, and avoid dangerous obstacles.
- **Musical Environment** - Platforms and obstacles interact with the rhythm of the background music.
- **Weapon System** - Use three unique musical weapons: Guitar, Trumpet, and The secret weapon.
- **Power-ups** - Gain temporary abilities such as Speed Boost and Spring Jump.
- **Collectibles** - Collect coins, Easter Eggs, and other useful items.
- **Combat System** - Fight enemies and face a final boss before reaching the ending.

## 🕹️ Controls

| Key | Action |
|---|---|
| A | Move Left |
| D | Move Right |
| Space | Jump |
| J | Attack |
| 1 | Select first weapon |
| 2 | Select second weapon |
| 3 | Select third weapon |
