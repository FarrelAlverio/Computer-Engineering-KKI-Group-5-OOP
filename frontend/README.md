# Frontend (Java + LibGDX)

Add your actual IntelliJ/LibGDX source modules here, after the team agrees on the existing Gradle module and Java package name.

Suggested packages inside the existing Java source root:
- screens/ — menu, gameplay, game over, ending
- entities/ — player, enemies, collectibles, power-ups
- world/ — platforms, zones, beat-controlled platforms
- combat/ — guitar, trumpet, piano, projectiles
- systems/ — collisions, health, beat timing, audio, saves
- patterns/ — strategy, factory, observer
- ui/ — health, coins, missions, weapons
- data/ — save models and settings

Do not create a second Java source root if the actual IntelliJ project already has one.
